# Linked research workspaces

Open **LAYOUTS ▾ → Linked Security Research** for profile, chart, financial statements, field inspection and a watchlist. All five panels use the red security group. Click a stock in the watchlist: the other panels load it while keeping their functions, and the watchlist remains open.

The selector beside each panel number offers Unlinked, Red, Green, Blue and Yellow. Matching colors share security changes across compatible screens included in the current layout, in the same window. On a phone these layout members can be behind panel tabs and still follow; panels excluded by the layout do not. A security-specific panel keeps its function and command arguments. An equity-only financial screen skips a currency selection; global screens retain their content. Assigning a group does not immediately change existing securities. A later security selection synchronises eligible members.

A plain security-link click in a linked global monitor publishes its selection when at least one compatible visible peer exists, including when that peer already has the selected security. Without such a peer it opens the security normally. An explicit function link or shift-click still opens the requested screen. Hidden panels retain their content. Back/forward security changes also update compatible peers; every panel retains its own bounded history and automatic changes do not steal focus.

Both workspace autosave and named layouts retain group choices. Named layouts restore their original routes without forcing all members onto one security, through either the LAYOUTS screen or the top-bar menu. Presets/older layouts without groups open unlinked. Each desktop window has its own layout and groups.

Pending autosave writes flush when the page closes, so an immediate reload after restoring a layout keeps the last visible screens and link groups.

Headers and command placeholders show familiar short mnemonics such as `DES`, `GP`, `FA` and `FLDS`, with a `<GO>` cue in headers. The descriptive function code stays visible and saved routes keep canonical names. **SETTINGS → Show short function mnemonics and <GO> cues** switches this display off; both command forms continue to work. Help lists both names.

These are local panel workflows. They do not provide Bloomberg Launchpad component/API integration, enterprise sharing or licensed data coverage. The [workflow audit](bloomberg-parity.md) records that boundary.
